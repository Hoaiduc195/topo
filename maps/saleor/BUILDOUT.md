# Draft build-out plan: Saleor Commerce

Generated by `pipeline/analyze.py` from the map (2,120 boxes). Items are ranked by leverage (how much of the system each one touches) over a rough effort estimate from the number of files behind its evidence. Every item is a proposal to check against the code with the owner, not a decision. Links open the map at the evidence; the numbers behind each item are in `ANALYSIS.md`.
